# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within REMOTE4REAL, please do NOT create a public issue.

Instead, please send an advisory report to the lead developer (**alchemist4real**) or open a private GitHub Security Advisory on the repository.

All security vulnerabilities will be promptly investigated and resolved.

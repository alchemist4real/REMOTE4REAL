# REMOTE4REAL — Mobile Application (React Native / Expo)

Full React Native mobile controller application with Monochromatic Minimalist White Void design, OffBit typography, native 120Hz gesture handling, and hardware acceleration.

---

## 🚀 How to Run:
```bash
npm install
npx expo start
```
- Scan QR code via **Expo Go** on Android / iOS.
- Or press `w` to run directly in web browser.
